# LANES visual system and generated assets

Working concept: `library-concept.png`, selected during the authorized build and
used as the primary library reference. No separate user design approval was requested.
The full app extends its library/selected-track system into playlists, settings,
profile, leaderboards and gameplay. No design approval is implied by this record.

Tokens: ink `#0c0d12`, surface `#14161e`, line `#252834`, muted `#9aa2b9`, lime
`#c7ff5e`, white `#f5f6fa`. DM Sans Variable is the UI font; Manrope Variable is
the heading/score font. Both are bundled from Fontsource for offline desktop use.
Primary controls are lime, secondary controls use charcoal borders, and selected
rows/navigation use a translucent lime tint. Corners are 6–10 px; icons are Lucide
outline components. Notes use five stable lane colors and a lime judgement line.

The composition uses a left navigation rail, open library table, and right track
inspector. At reference size the sidebar is 254 px and the inspector 455 px. At
smaller widths it collapses to labeled accessible icons and stacks the track
inspector below the library. Controls and text remain real DOM elements.

Artwork was generated with the built-in ImageGen tool, then compressed to WebP
for runtime delivery. Saved files:

- `docs/design/library-concept.png`: complete primary-screen design concept.
- `public/art/aurora.png`: original production background artwork.
- `public/art/aurora.webp`: optimized runtime banner/cover artwork.
- `public/icon.svg`: code-native five-lane brand mark; PNG/ICO variants are generated by the build.

The banner and covers use original art in explicit media frames, with an edge
readability fade behind code-native banner text. The lane HUD, note bars, hit line,
keycaps, and simple logo remain functional vector/canvas geometry intentionally;
there are no character/platform sprites in this rhythm-game design.
