# Project Management Tools

This folder contains neutral workflow tools generated by Reponator.

## Files

- `manifest.json` records the generated scaffold.
- `ledger.js` reads `docs/dev-ledger.md` and can print a commit message from Complete entries.
- `todo.js` lists and appends Markdown planning tasks in `docs/planning/To-do.md`.
- `handoff.js` creates a durable handoff summary under `docs/handoffs/`.
- `version-show.js`, `version-sync.js`, and `version-bump.js` keep project version values aligned.
- `version-targets.js` inventories the real first-party app/server/installer version fields; vendor and dependency metadata are excluded.
- `stack-command.js` is the retained creation-time stub; package.json now invokes real tools under `tools/build/` instead.
- `commit-release.js` bumps the requested version part, commits, and pushes when a remote exists.

## Common Commands

```powershell
npm run todo
npm run todo:add -- "Write first milestone"
npm run ledger:message
npm run handoff
npm run version:show
npm run scaffold:check
npm run deploy:check
npm run commit -- "initial release"
```

`manifest.json` retains historical creation-time seed hashes and separately records
the current implementation paths, runtime assumptions, artifact layout, commands,
and local/shared ownership. `scaffold:check` validates current paths and command
names; seed hashes are not assertions that implementation files remain unchanged.
